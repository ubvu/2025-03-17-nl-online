Installeer Zoom

Ga naar de officiele Zoom website om Zoom te downloaden en te installeren als je Zoom nog niet eerder gebruikt hebt.

Tips voor je werkplek

Zoals bij alle Carpentries workshops leer je door 'mee te coderen' met de docenten. Om dat te kunnen doen, is het nodig dat je zowel Zoom als de software waarover je leert (OpenRefine, Python, etc) geopend hebt. We raden één van de volgende opstellingen aan, zodat je beide tegelijk kunt zien.

  • Twee beeldschermen: Als je twee beeldschermen beschikbaar hebt, kun je één beeldscherm gebruiken voor Zoom, en de andere voor de software tool.
  • Twee apparaten: Als je niet beschikt over twee monitors heb je misschien een ander apparaat beschikbaar naast je computer, bijvoorbeeld een tablet of smartphone. Je kan dan het kleinere apparaat gebruiken voor Zoom, en je computer voor de software tool.
  • Verdeel je scherm: Als je maar één scherm en apparaat hebt, moet je Zoom en software naast elkaar openen. Probeer voor de start van de workshop uit wat het beste voor je werkt
